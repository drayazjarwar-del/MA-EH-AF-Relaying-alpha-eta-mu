# MA-EH-AF-Relaying-alpha-eta-mu

MATLAB simulation and analysis codes accompanying the manuscript:

**Unified Analysis and Optimisation of Movable-Antenna-Assisted Energy Harvesting AF Relaying over α–η–μ Fading Channels**

Authors: **Ayaz Hussain** and **Imran Shafique Ansari**

This release reproduces the numerical results in Figs. 2–13 of the revised manuscript. Fig. 1 is the conceptual system-model diagram and is not generated by MATLAB.

## Requirements

- MATLAB R2020a or newer is recommended.
- The manuscript calculations were tested in MATLAB R2026a Update 3 on 64-bit Windows.
- The scripts are self-contained and use local functions; no external data files are required to run the figure scripts.
- Random seeds are set inside the scripts for reproducibility.
- Several scripts use very large Monte Carlo sample sizes. Reducing the sample count is useful for a quick test but will not reproduce the publication-level markers exactly.

## Running a figure

Open MATLAB in the repository root and run, for example:

```matlab
run('code/Fig06_Fading_Generality.m')
```

Each script contains the numerical parameters and local functions required for that figure. Generated PDF/PNG/CSV/MAT files are written either to the current working directory or to the figure-specific output directory created by the script.

## Reproducibility notes

### Spatial correlation

Fig. 4 uses a Clarke/Jakes-type spatial field-correlation matrix

```text
R[p,q] = J0(2*pi*|p-q|*Delta/lambda_c)
```

for uniformly spaced candidate positions. The i.i.d. MA result remains the exact analytical benchmark, whereas the correlated cases are generated by Monte Carlo simulation.

### Relay-power saturation

Fig. 5 evaluates the finite relay-power model

```text
P_R^sat = min(kappa*P_S*X, P_R,max)
```

and compares it with the linear-EH benchmark.

### Classical fading validation

For Fig. 6, the analytical heterogeneous Rayleigh/Nakagami-m curve is obtained from the general α–η–μ formulation using the corresponding special-case parameters. The associated Monte Carlo samples are generated independently from the classical exponential (Rayleigh power) and Gamma (Nakagami-m power) distributions.

### Low-outage Monte Carlo points

The high-sample-count scripts are intended to support validation in low-outage regions. Fig. 6 explicitly omits simulation markers having fewer than 20 observed outage events.

### Optimization

The optimization scripts use enumeration of feasible candidate-position allocations, a coarse one-dimensional search, and local refinement without assuming convexity. `Fig13_Joint_Optimization.m` also records the MATLAB/runtime environment and excludes Monte Carlo validation from the reported analytical-optimization runtime.

## Reference data

`reference_data/Fig08_Bounds_Data.csv` contains the supplied numerical data corresponding to the Fig. 8 bounds-validation run. The Fig. 8 script regenerates this data independently.
